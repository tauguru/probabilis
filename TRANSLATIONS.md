# Translations

Translations are granted on a case-by-case basis, provided:

1. **The content is not changed** — translation only, no modifications to values, principles, or anti-patterns
2. **The content is not used commercially** — translations may not be sold or monetized in any form
3. **The translation is given back to this public repo** — all approved translations are contributed back and published here under the same license

To request permission, open an Issue using the **Translation Request** template.

## Translation process

1. Open an Issue using the **Translation Request** template
2. Specify the language and ISO 639-1 code
3. Receive approval from the author
4. Fork the repository
5. Translate all content (manifesto at minimum), without modifying the substance
6. Submit a PR — the author will create the language branch
7. Once merged, you become maintainer of your language branch

## Language navigation format

Each README includes a language navigation line at the top:

```
🇬🇧 EN · 🇫🇷 FR · 🇷🇴 RO
```

- The current language is plain text (not linked)
- All others link to their branch: `https://github.com/tauguru/probabilis/tree/xx`
- ISO 639-1 codes in alphabetical order
- The attribution block is never translated
