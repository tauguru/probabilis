# Contributing to Probabilis

Thank you for your interest in contributing to Probabilis.

---

## What can be contributed

| Type | Process |
|---|---|
| Typo / correction | PR directly with template |
| Wording improvement | PR with explanation |
| New anti-pattern | Issue first (discussion), then PR if approved |
| Principle change | Issue first (mandatory discussion), then PR if approved |
| New translation | Issue (permission request) → Approval → Fork → PR |

## What only the author may change

- Version numbers
- `CHANGELOG.md`
- `LICENSE.txt`

## Intellectual property

All contributions grant the author a non-exclusive, irrevocable license to use the contributed
content as part of the Probabilis project. Contributors retain their own copyright.

## Process for external contributors

1. Search existing Issues and Pull Requests before opening a new one
2. Use the appropriate Issue template
3. Wait for author feedback before starting significant work
4. Submit a PR using the Pull Request template

## Style guidelines

- Write in clear, direct language
- Match the register and tone of the existing text
- Sentence case for headings
- UTF-8 encoding, LF line endings
